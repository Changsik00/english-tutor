## 이 영상에서 가져온 내용

이 영상을 분석해서 `english_grammar_notes/chapters/ch14_관계사.md`의 **Unit 097 (관계부사)** 을 보강했습니다. 추가된 내용(전부 새로 작성, 영상 문장을 그대로 옮기지 않음):

1. **관계대명사 vs 관계부사 판별법** — 선행사를 관계사절에 다시 넣어보아 전치사가 필요한지로 구분하는 방법, 그리고 관계부사 뒤에 전치사가 남으면 대부분 틀렸다는 점검 팁.
2. **자동사·타동사 함정** — visit, enter, attend, reach, resemble, marry, await, mention, discuss처럼 전치사 없이 목적어를 바로 받는 동사들을 관계부사 where로 잘못 연결하는 실수. 관계부사 문제의 상당수가 실제로는 [[ch03_문장의형식]]의 자동사/타동사 구분 문제라는 점.
3. **관계부사 → that 치환**과, 선행사를 생략한 자리에는 that을 쓸 수 없다는(명사절 that과 혼동됨) 제약.
4. **관계부사의 계속적 용법** (콤마 + when/where) — 기존 문서에 없던 내용으로 신규 추가.
