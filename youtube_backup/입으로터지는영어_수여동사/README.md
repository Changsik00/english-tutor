## 안내

- 각 `lectures/*.md` 파일은 YouTube **자동 생성 한국어 자막**을 dedupe(중복 줄 제거)만 하고 이어붙인 것입니다. 사람이 교정하지 않았으므로 오탈자/동음이의어 오인식이 있을 수 있습니다. 정확한 내용은 원본 영상을 확인하세요.
- 원본 저작권은 채널(입으로 터지는 영어)에 있습니다. 이 백업은 개인 학습·연구 목적의 로컬 보관용이며, 우리 프로젝트 콘텐츠에 문장을 그대로 복사해 넣지 않습니다.
- 이 저장소는 퍼블릭 GitHub 저장소이므로, `lectures/` 폴더(자막 전문)는 `.gitignore`에 등록되어 **git에 커밋되지 않습니다**. 이 인덱스(README.md)만 저장소에 남습니다.
- 두 영상의 핵심 주장(사실관계)을 검증한 뒤, 확인된 내용만 `ch03_문장의형식.md` Unit 017에 원문 인용 없이 새로 작성해 반영했습니다.

## 검토 메모 (정확성 확인)

- **1편의 "게르만어 기원=4형식 가능, 라틴어 기원=3형식만 가능"이라는 주장**은 실제 영어 통사론에서 알려진 경향(Green's Latinate Constraint 등)과 대체로 일치하지만, 절대적 규칙은 아닙니다(예: cost는 라틴어 계열 어원이지만 4형식 전용). 책에는 "참고용 기억법"으로만 소개하고, 예외가 있다는 점을 명시했습니다.
- **2편의 "cost/charge/fine/bet은 to를 쓴 3형식이 불가능하다"는 주장**은 표준 영문법 자료와 일치하는 정확한 내용으로 확인되어 그대로(원문 인용 없이 새로 작성) 반영했습니다. "bill"은 영상 자막에서 제목에만 등장하고 본문에서 구체적으로 다루지 않아, 확인 없이 목록에 넣지 않았습니다.
- charge의 "charge it to my account" 같은 표현은 "청구 대상 계좌"에 to를 쓰는 별개 용법이라 혼동하지 않도록 책에 별도로 각주했습니다.
