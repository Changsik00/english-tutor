## 검토 메모 (정확성 확인)

- 핵심 내용(suggest/recommend/insist/demand/order/request/propose/ask/prefer 등 주장·제안·요구·명령 동사 + that절 → 인칭·시제 무관 동사원형, "가정법 현재")은 표준 영문법(mandative subjunctive)과 정확히 일치합니다. 기존 책(ch13 접속사, ch15 가정법 어디에도) 전혀 다루지 않던 내용이라 새 Unit으로 신설했습니다.
- 영상이 짚은 "같은 동사(insist, suggest)라도 문맥에 따라 사실 진술(일반 시제)과 가정법 현재(동사원형)로 갈린다"는 포인트는 실제로 매우 유용하고 정확한 구분이라 표와 함께 그대로 반영했습니다.
- "영국식은 should+동사원형, 미국식은 동사원형 선호"라는 설명도 표준적으로 알려진 사실이라 반영했습니다.
- 영상 후반의 wish/would rather/suppose/imagine + 과거형(가정법 과거) 부분은 이미 ch15 Unit 100(I wish)에 있는 내용이라 별도로 반영하지 않았습니다.
