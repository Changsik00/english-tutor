## 검토 메모 (정확성 확인)

- 영상 대부분(원인=-ing, 결과=-ed, be interested in/satisfied with 같은 전치사, 사역동사 뒤 -ing/-ed 구분 등)은 이미 ch09 Unit 055에 있던 내용과 중복이었습니다.
- 새로웠던 것은 "You disappoint me"처럼 능동으로 직접 말하면 비난처럼 들려 부담스럽기 때문에, 감정을 느끼는 사람을 주어로 놓은 수동형(I am disappointed)이 완곡어법으로 훨씬 널리 쓰이게 되었고, 그 결과 disappointed 같은 단어가 아예 독립된 형용사로 굳어졌다는 설명입니다. 이는 강사 개인의 설명 방식(엄밀한 학술적 각주가 있는 정설이라기보다 화용론적으로 타당한 정리)이라 판단해, 책에는 "이렇게 볼 수 있다"는 정도의 어조로 반영했습니다.
- 영상에서 "surprised/amazed는 아직 수동태 성질이 남아 by를 쓸 수 있고, interested/satisfied는 이미 형용사로 굳어져 by를 쓸 수 없다"고 딱 잘라 설명한 부분은, 실제로는 surprised by/at, interested by(드묾)/in, satisfied by/with처럼 상당수가 여전히 by도 허용하는 경우가 많아 **과도하게 단순화된 이분법**이라고 판단했습니다. 이 부분은 책에 반영하지 않고, 기존 전치사 목록(주의사항)을 그대로 유지했습니다.
