# 디자인 시스템

이 문서는 `영문법 기초 완성 노트` 웹사이트(Docusaurus)의 비주얼 규칙집입니다. CSS/컴포넌트 작업은 전부 이 문서를 따릅니다. 새 페이지·컴포넌트를 추가할 때도 여기 정의된 토큰과 패턴을 재사용하고, 새 값이 필요하면 먼저 이 문서에 추가합니다.

## 원칙

1. **한국어 본문 가독성이 최우선**. 줄 길이·행간·폰트는 영어 UI 기본값이 아니라 한국어 장문 읽기 기준으로 정한다.
2. **콜아웃(admonition)이 곧 학습 장치**. 색과 아이콘만으로 "이건 원리다 / 이건 흔한 오해다 / 이건 정의다"를 구분할 수 있어야 한다.
3. **기존 Infima 구조를 존중**. Docusaurus 테마를 스와이즐하지 않고, 토큰 오버라이드 + 애드온 컴포넌트로만 구현한다(현재 방식 유지).

## 타이포그래피

- 폰트: **Pretendard**(OFL, 셀프호스팅 — `pretendard` npm 패키지의 static CSS를 `custom.css`에서 `@import`). 외부 CDN 요청 없음.
  ```
  font-family: 'Pretendard', -apple-system, BlinkMacSystemFont, 'Apple SD Gothic Neo', 'Malgun Gothic', sans-serif;
  ```
- 본문(`article`): `font-size: 1.05rem`, `line-height: 1.9`, 문단 사이 여백 `1.1em`.
- 본문 최대 너비: 기존 Infima 기본(`--ifm-container-width`)보다 살짝 좁게(약 760px)하여 한 줄에 너무 많은 한글이 들어가지 않게 한다.
- 헤딩 스케일: `h1 2.0rem/700`, `h2 1.55rem/700`(위쪽에 얇은 강조 보더), `h3 1.2rem/600`, `h4 1.05rem/600`. 챕터 내 `## Unit 0XX` 헤딩은 유닛 번호를 배지 스타일(작은 pill)로 강조.
- 예문 영어 문장은 본문보다 살짝 크게(`1.05em`) + `font-weight: 600`로 한국어 설명과 시각적으로 분리.

## 색 토큰

라이트 모드 기준(다크 모드는 각 항목의 밝은 변형, `[data-theme='dark']`에서 오버라이드):

| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--ifm-color-primary` | `#4f46e5` (인디고) | `#a5b4fc` | 브랜드 컬러, 링크, 버튼 |
| `--egn-color-definition` | `#2563eb` | `#7dabfb` | `:::definition` 콜아웃 |
| `--egn-color-myth` | `#d97706` | `#fbbf24` | `:::myth` 콜아웃 |
| `--egn-color-principle` | `#0d9488` | `#5eead4` | `:::principle` 콜아웃 |
| `--egn-color-review-again` | `#dc2626` | `#f87171` | 복습 self-grade "다시" 버튼 |
| `--egn-color-review-unsure` | `#d97706` | `#fbbf24` | 복습 self-grade "헷갈림" 버튼 |
| `--egn-color-review-good` | `#16a34a` | `#4ade80` | 복습 self-grade "기억남" 버튼 |

기존 진단: 현재 `--ifm-color-primary`가 `#2563eb`(파랑)인데 `:::info`(원리 박스)도 같은 파란 계열이라 "브랜드색"과 "원리 콜아웃"이 구분되지 않았음 → 브랜드는 인디고로 옮기고, 원리는 기존 파랑 계열(`:::info`)을 유지해 구분한다.

## 콜아웃 5종

기존 2종(`:::tip` 초록 — 학습목표/공부법, `:::info` 파랑 — 원리 소개) + 신규 3종:

| 타입 | 아이콘/제목 예시 | 색 | 용도 |
|---|---|---|---|
| `:::definition` | 📘 정의부터 다시 세우기 | `--egn-color-definition` | 흔히 쓰이는 느슨한 정의를 정확한 정의로 재정립 |
| `:::myth` | 💭 흔한 오해 | `--egn-color-myth` | 오해/속설을 먼저 보여주고 반박하는 도입부 |
| `:::principle` | 🧭 원리 확장 | `--egn-color-principle` | 챕터 대표 원리 외에 유닛 국소적으로 적용되는 하위 원리 |

구현: Docusaurus v3는 `:::type[제목]` 문법에서 등록되지 않은 커스텀 타입도 렌더링하되 기본 스타일(`note`)로 폴백한다. `custom.css`에서 생성되는 클래스(`.theme-admonition-definition` 등, 실제 클래스명은 구현 시 빌드 결과로 확인)에 위 색을 입혀서 시각적으로 구분한다.

## 레이아웃 컴포넌트 패턴

- **챕터 헤더**: `<ChapterProgress>` 위에 챕터 번호 배지 + 제목 + (신규) 유닛 앵커 칩 목록(가로 스크롤 가능한 작은 pill 리스트, `data/units.json` 재사용)을 추가해 긴 챕터 안에서 바로 원하는 유닛으로 이동 가능하게 한다.
- **유닛 구분**: 각 `## Unit 0XX` 시작 전에 얇은 구분선(`border-top`) + 여백(`3rem`)을 둬서 스크롤 중 유닛 경계가 뚜렷하게 보이게 한다.
- **연습문제 카드**: 기존 `<details>` 유지(접근성·SEO 상 markdown 텍스트가 그대로 남는 게 유리하므로 커스텀 React 컴포넌트로 바꾸지 않는다). 다만 카드 느낌을 강화: 왼쪽에 옅은 색 보더 바, 문제 번호를 작은 원형 배지로.
- **복습 self-grade 버튼 행**: 정답 `<details>` 안, 문제별로 "🔴 다시 / 🟡 헷갈림 / 🟢 기억남" 3버튼을 가로로 배치. 선택된 버튼은 배경색 채움, 나머지는 아웃라인만.
- **단어장 카드**: 단어(굵게, 1.1em) + 품사 pill(회색 배경, 작은 대문자) + 뜻 + 패턴 태그 pill(`--egn-color-principle` 옅은 배경) + 예문(작은 글씨, 이탤릭 없이 — 한글엔 이탤릭 대신 색 톤 다운으로 구분).
- **홈페이지**: 히어로에 "원리로 이해하는 영문법" 카피 + 5원리를 5개 아이콘 카드로 요약, 하단에 시작하기/전체목차/오늘의 복습 3개 CTA 카드.

## 간격 스케일

`4 / 8 / 12 / 16 / 24 / 32 / 48px` 만 사용(임의 값 지양). CSS 커스텀 프로퍼티로 `--egn-space-1`~`--egn-space-6` 정의.

## 다크 모드

`respectPrefersColorScheme: true`는 유지. 모든 신규 토큰은 라이트/다크 쌍으로 정의하고, 대비(WCAG AA, 본문 텍스트 기준 4.5:1) 확인 후 적용한다.
